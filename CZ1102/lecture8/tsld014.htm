Common Programming Errors

  • Forget & in scanf, for example,

      scanf("%d", x);
    • may give error message "segmentation fault"

  • Used \n or space in scanf.

  • Forget to include <stdio.h>. This courses serious error if EOF and FILE are used.

  • Used = instead of == in condition, e.g.,

      if( x = 1) . . .
