Multidimensional Array as Arguments

  • The dimensions of the array must be specified in function definition. E.g.,



      print_table(int t[10][4])
      {
      . . .
      }

      main()
      {
      int t[10][4];
      . . .
      Print_table(t);
      }

    The first size can be omitted.
