Initializing Multidimensional Arrays

  • Multidimensional array can be initialized element by element:

      int nums[2][3];

      nums[0][0] = 2;
      nums[0][1] = 4;
      nums[0][2] = 6;
      nums[1][0] = -9;
      nums[1][1] = -7;
      nums[1][2] = -5;

  • Or initialized during declaration:

      int nums[2][3] = {

      {2, 4, 6}, {-9, -7, -5}}
