String-Handling Functions

  • String Concatenation

  • With the declaration and initialization:

    • s1[10] ="The ";

      s2[4] = "CZ";

    The function (with string.h included)

      strcat(s1, s2);

    append the string s2 to the end of string s1, i.e., s1 now becomes

    "The CZ".
