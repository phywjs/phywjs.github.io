Dynamical Memory Allocations of Arrays

  • Dynamical allocation of one-dimensional array is easy:

    • double *a; /* define a pointer */

      a = calloc(100,
      sizeof(double));
      /* memory for 100 elements of type double created */
      a[5] = 4.5; /* use a as an array */
