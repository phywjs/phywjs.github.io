Installation Instructions

Work under MS-DOS prompt. Assume you have downloaded unzip.exe (which should be in your search pass, in, e.g., C:\windows), and saved all the zip files in c:\tmp.

Follow this example, substituting paths as appropriate (type the bold parts):

C:\xx> cd C:\
C:\> mkdir djgpp
C:\> cd djgpp
C:\DJGPP> unzip  c:\tmp\djdev201.zip
C:\DJGPP> unzip  c:\tmp\faq210b.zip
C:\DJGPP> unzip  c:\tmp\rhide14b.zip
C:\DJGPP> unzip  c:\tmp\bnu281b.zip
C:\DJGPP> unzip  c:\tmp\gcc281b.zip
C:\DJGPP> unzip  c:\tmp\mak3761b.zip
C:\DJGPP> echo set PATH=%PATH%;C:\DJGPP\BIN>> c:\autoexec.bat
C:\DJGPP> echo set DJGPP=C:\DJGPP\DJGPP.ENV>> c:\autoexec.bat
Ctrl-Alt-Del to reboot

It may be necessary to edit the autoexec.bat file (e.g., multiple lines of path definition). The default executable file name for gcc on DOS is a.exe (not a.out as on Unix).

Note: Sample compile command: gcc hello.c -o hello.exe

You start the integrated development environment by typing rhide, which is very similar to Turbo C/Borland C++. There is a build-in editor, a debugger, menu choices for compilation and run in this environment.

For complete DJGPP package, see the site http://www.delorie.com/djgpp/
