Increment (++) Operator

  • When we execute

      ++x (prefix)

  • two things happen:

    • The value of the variable x is increased by 1.
    • The value of the expression ++x is equal to the new value (original value plus 1).

  • When we execute

      x++ (postfix)

  • two things happen:

    • The value of the variable x is increased by 1. Same as ++x.
    • The value of the expression x++ is equal to the old value (original value of x).
