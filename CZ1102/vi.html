Installation Instructions

Work under MS-DOS prompt. Assume you have downloaded unzip.exe (which should be in your search pass, in, e.g., C:\windows), and saved all the zip files in c:\tmp.

Follow this example, substituting paths as appropriate (type the bold parts, type EXACTLY as shown if you do not understand what's going on):

C:\WINDOWS> cd C:\
C:> unzip  c:\tmp\gvim51.zip
C:> echo set PATH=%PATH%;C:\VIM-5.1>> c:\autoexec.bat
Ctrl-Alt-Del to reboot

For the path to take effect, you need the last step of reboot. The editor is called gvim, you can rename it vi if you want to. All the gvim related files are in the directory C:\VIM-5.1.

For complete VIM package, see the site http://www.vim.org/
