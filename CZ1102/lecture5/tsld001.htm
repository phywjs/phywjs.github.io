Operators

  • A binary operator combines two values to get one result:

      x OP y

    where OP is any binary operators such as +, -, *, /, ==, !=, >, &&, or even =.

  • A unary operator takes one value and gives one result:

      OP x

    where OP can be +, -, &, !, ++, etc.
