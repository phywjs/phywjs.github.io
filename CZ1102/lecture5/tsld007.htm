Assignment Operators

  • The operators used in the form

      x op= y (no space between op and =)

    is equivalent to

      x = x op ( y )

    where op is +, -, *, /, %, >>, <<, &, ^ or |.

  • Examples:

    • x += 3 -> x = x + 3

      y *= x+z -> y = y*(x+z)
