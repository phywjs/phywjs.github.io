Using Array Name

    float on_time_rate[100];


    float *ptr;

    ptr = on_time_rate;

    Or equivalently

    ptr = &on_time_rate[0];

  • Once ptr is assigned value, you can use ptr as an array, e.g.,

    ptr[0], ptr[1], …, ptr[99]

    This is the same as

    *ptr, *(ptr+1), …, *(ptr+99)
