Expression/Action

  • An expression consists of variables and operators of valid combinations. E.g.,

    x > 0, y == 0,

    or just x.

  • An action is a statement ending with a semicolon “;”, or several statements enclosed in braces. E.g.,

    {

    x = 1;

    printf("x=%d\n", x);

    x = x + 1;

    }
