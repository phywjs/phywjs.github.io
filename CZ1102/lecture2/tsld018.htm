If-else, Example

    Int code;


    code = 1;

    if ( code == 1 )

    printf("CZ Courses\n");

    else

    printf("MA Courses\n");

    printf("*** THE END ***");

    the output is

    CZ Courses

    *** THE END ***

    If code is set to 0 or any value other

    than 1, the output becomes:

    MA Courses

    *** THE END ***
