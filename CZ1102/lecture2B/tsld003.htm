Compile and Run

  • The C program pg64.c is compiled as

      gcc pg64.c -o pg64 ?

  • The executable pg64 is run

      pg64 ?

  • Assuming the file ph.in exists with

      7.2e-5 1.4e-6

      2.9e-11 6.9e-8 2.8e-10
