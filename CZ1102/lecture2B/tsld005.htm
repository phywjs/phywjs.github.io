When to Use the Semicolon ";"

  • Semicolon ";" is used to terminate a declaration or statement:

      int i, j;

      i = 5;
      printf("%d\n", i);

  • Omitting ";" in the above courses a syntactical error.

  • There should be no ";" after #include < … > or similar preprocessing directives.
