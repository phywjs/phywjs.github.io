Expression and Action

  • Expression can be logical comparison, for example

      x > 0, x==2, or x && y.

  • Expression can also be

      x+y, or simply just x.

  • Action can be a single statement like

      x = 3;

  • Or a sequence of statements, each ending with a semicolon ";". Braces { … } are necessary. For example:

      {

      x = x + 3;
      printf("%d\n", x);
      x = y + 1;
      }
