Typedef Construct

  • C typedef construct associates a built-in or user-defined type with a new (type) name.

    typedef oldname newname;

    • struct pair {

      double real;
      double imaginary;
      };
      typedef struct pair complex;
      typedef int* int_ptr;

      complex a b c;
      int_ptr p, q;
