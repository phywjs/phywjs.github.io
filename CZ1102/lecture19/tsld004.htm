Declare and Initialize a Structure

  • Example:

      int n, ns[5];

      float r, ts[4];
      struct element e1, es[3];

      strcpy( e1.name, "hydrogen");
      strcpy( e1.symbol, "H");
      e1.aWgt = 1.0;
      e1.mass = 3.0;

  • To access each field of a structure, use the structure's name followed by a period '.' and the name of the field.
