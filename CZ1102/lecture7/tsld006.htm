Control Flow

  • while (expr) { action }

    • Loop until expr becomes false.

  • do { action }

    while (expr);

    • Loop but check at the end.

  • for (init; condition; update) { action }

    • More general loop.

  • if ( ), or if ( ) action1 else action2.

    • Conditional execution.
