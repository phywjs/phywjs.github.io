\problem  The LISP {\tt (derivative $f$ $x$)} function that we have
discussed did not simplify
expressions like {\tt (+ 0 x)} or {\tt (* 1 2)}.  Write your (simpler) 
version of {\tt (simplify $expr$)} which does some simple algebraic 
simplification based on the following 11 rules. 
\itemitem{1.} Replace {\tt (+ $f$ 0)} or {\tt (+ 0 $f$)} by $f$.
\itemitem{2.} Replace {\tt (- $f$ 0)} by $f$.
\itemitem{3.} Replace {\tt (- 0 $f$)} by {\tt (- $f$)}.
\itemitem{4.} Replace {\tt (* $f$ 0)} or {\tt (* 0 $f$)} by 0.
\itemitem{5.} Replace {\tt (* $f$ 1)} or {\tt (* 1 $f$)} by $f$.
\itemitem{6.} Replace {\tt (/ 0 $f$)} by 0 if $f$ is not 0.
\itemitem{7.} Replace {\tt (/ $f$ 1)} by $f$.
\itemitem{8.} Replace {\tt (\char`\^\ $f$ 0)} by 1.
\itemitem{9.} Replace {\tt (\char`\^\ 0 $f$)} by 0.
\itemitem{10.} Replace {\tt (\char`\^\ $f$ 1)} by $f$.
\itemitem{11.} Replace {\tt ($opr$ $n$ $m$)} by its evaluation where
$opr$ is {\tt +}, {\tt -}, {\tt *}, {\tt /}, {\tt\char`\^}, and 
$n$ and $m$ are numbers.
\item{} The function has to recursively simplify all subexpressions (from
inside out) similar to the {\tt derivative} function.  Try out
some sample expressions generated by {\tt derivative} and your own test input.


\problem Using the rule-based programming style of Mathematica,
define your own indefinite integration 
function {\tt integ[$expr$, $x$]}, so that it can at least do integrations
over polynomials.  Some of the rules are
\itemitem{1.} $\int c\, dx = c\, x$.
\itemitem{2.} $\int x^n\, dx = x^{n+1}/(n+1)$.
\itemitem{3.} $\int f(x) + g(x) \,dx = \int f(x)\,dx + \int g(x)\,dx$.
\itemitem{4.} $\int c f(x) \,dx = c \int f(x)\,dx$.
\item{} Add more integration ability if you can, e.g., $\sin$, $\exp$, etc. 
Test it thoroughly.  


\problem A graph is defined as a set of vertices and a set of
edges which connect two vertices.   A vertex needs not to be 
always connected.  We'll consider undirected graph,
so that an edge is a set of two (unordered) vertices.
(a) Introduce
a data structure in Mathematica to represent graphs.  (b)  We'll say a
graph is unlabelled if we do not mark the vertices, so that
all vertices and edges look the same. The symmetry number of an unlabelled
graph is the number of different ways of labelling the graph, in such a
way so that they are topologically distinct.  Two labelled graphs are
topologically distinct if their connectivities are different.  Higher
symmetry number actually means that the graph is less symmetric. 
For example, the square graph has symmetry number 3.  Write
a Mathematica function to compute the symmetry number of a graph. Hint:
given the input graph (which is necessarily a labelled graph), generate
the $n!$ different labeling of the graph.  Transform each of the labelled
graph into a canonical representation of unlabelled graph, so that each 
graph has a unique
representation.  Count the number of distant graphs in this canonical 
representation.   Give extensive examples of your computations on
graphs.
