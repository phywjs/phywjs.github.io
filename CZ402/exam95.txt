\problem In certain quantum mechanical calculation involving fermions,
we need to evaluate the value of fermion operator product of the form
$a b^\dagger c \cdots d a^\dagger c$.  The result of this product is
either $-1$, or 0, or 1.  The operators follow the rules:
$$\eqalign{ 0\, a & = a\, 0 = 0, \quad 1\, a = a\, 1 = a, \quad
           a\, a = 0, \quad a^\dagger a^\dagger =  0, \cr
           b\, a & = - a\, b, \quad 
           b^\dagger a^\dagger = - a^\dagger b^\dagger, \quad
           b\, a^\dagger = - a^\dagger b, \quad a \neq b, \cr
           a\, a^\dagger & = - a^\dagger a + 1, \cr
}$$
where $a$ or $b$ is an arbitrary fermion operator.
For each operator $a$, there is a corresponding conjugate operator 
$a^\dagger$.  Their relation is defined by the last equation above.
In addition, any product sequence starting with a conjugate operator 
(with $\dagger$) or end with an operator without $\dagger$ is defined
to be 0.  Here are some examples, $a a^\dagger = - a^\dagger a + 
1 \rightarrow 1$;  $a b b a^\dagger = a\,0\,a^\dagger = 0$;
$a b b^\dagger a^\dagger = - a b a^\dagger b^\dagger = 
a a^\dagger b b^\dagger = (- a^\dagger a + 1 ) b b^\dagger = 
b b^\dagger = - b^\dagger b + 1 \rightarrow 1$.  

\item{} (a)  Propose a method to represent the conjugate of an operator 
in Mathematica.
\item{} (b) How would you implement the noncommutative operator 
multiplications in Mathematica?
\item{} (c)  Define the operator multiplication rules in Mathematica
so that the calculation of the product can be made automatic.

\problem Consider Lisp expressions of the forms restricted to the lists
with only two or three elements, {\tt ($opr$ $x$)}, or {\tt ($opr$ $a$ $b$)},
where the first element is always an atom (which is interpreted as a
binary operator or function name), while the second or third
element can be an atom or the restricted list.  

\item{} (a) Write a Lisp function which returns the total number of operators
($opr$) [including the operators nested inside ($\cdots$)] of the given 
expression.

\item{} (b) Define a Lisp function which translates from the restricted 
Lisp expression (prefix notation) to postfix notation similar to the
PostScript language.  The translated expression is a flat list where
$opr$ is after the operands.  One also translates the four special
operators {\tt +}, {\tt -}, {\tt *}, {\tt /} to {\tt ADD}, {\tt SUB}, 
{\tt MUL}, {\tt DIV}, respectively.
Note that in PostScript, when the code is read from left to
right, data are pushed on a stack; command ($opr$)
consumes the values on the stack, and result is pushed back on the stack.
Here are some examples of valid inputs and outputs produced by your 
function.  Watch out for the cases when the operands are again list 
expressions.
\smallskip
\def\tb{\qquad$\Rightarrow$\qquad}
\ll{(sin x) \tb  (X SIN)}
\ll{(+ 1 2) \tb (1 2 ADD)}
\ll{(- 5 2) \tb (5 2 SUB)}
\ll{(* a b) \tb (A B MUL)}
\ll{(/ 10 2) \tb (10 2 DIV)}
\ll{(op x y) \tb (X Y OP)}
\ll{(f (+ c d)) \tb (C D ADD F)}
\ll{(+ a (/ b c)) \tb (A B C DIV ADD)}
\ll{(* (+ a b) (- (f x) (/ c d))) \tb (A B ADD X F C D DIV SUB MUL)}
