\problem This problem tests your understanding of Mathematica
syntax and semantics.
Indicate the responses of Mathematica when the following
expressions are entered, assuming that each expression is given
to a fresh Mathematica session so that there should be no side effect
among subquestions.
{\def\{{\char`\{}
\def\}{\char`\}}
\def\_{\char`\_}
\def\^{\char`\^}
\smallskip
\halign{\t\t \hfil (#) &\quad \tt # \hfil &\t \hfil (#) &\quad \tt # \hfil \t\cr
1& \{1,2,3\} // f          &9&  \{\{a,b\},\{c,d\}\} .\{1,2\}    \cr
2& f @@ \{1,2,3\}          &10&  Map[ \#\^2\&, x+y+x]  \cr
3& FullForm[x\^3 + u*y]   &11&  Log /@ \{E, E\^2, 1\} \cr
4& x //. x -> x           &12&  Sum[1, \{5\}]  \cr
5& Head[x] == "Symbol"  &13&  Union[\{a,a,b\}] \cr 
6& MatchQ[f[a,b], f[x\_$\,$\_]] &14&  Expand[(1+x)\^2] >> tmp\cr
7& p || (q \&\& !q)       &15&  x=2; y==x  \cr

}
